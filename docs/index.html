Why CompanyScope?

Stop juggling 8 different APIs. CompanyScope aggregates Wikipedia, GitHub, SEC EDGAR, RDAP, OpenCorporates, web scraping, Hunter.io, and NewsAPI into a single structured response. One tool call, full company profile.

  • SEC financial data — Revenue, net income, total assets, stock tickers, and recent 10-K/10-Q filings
  • Tech stack detection — 19+ frameworks, languages, hosting, and analytics via DNS + HTTP headers
  • Corporate registry — Incorporation data from 140+ jurisdictions via OpenCorporates
  • Domain intelligence — RDAP lookups for registrar, domain age, and nameservers
  • Key people — Founders, C-suite, team members from Wikipedia and web scraping
  • Zero setup — No API keys, no accounts, no configuration. Connect and start querying.

6 MCP Tools

lookup_company

Full profile: description, founding, HQ, employees, tech stack, key people, financials, news, domain data

get_tech_stack

Detect 19+ frameworks, languages, hosting, and analytics from website + GitHub repos

get_key_people

Founders, executives, team members with titles from Wikipedia and web scraping

get_financials

SEC EDGAR: revenue, net income, assets, liabilities, stock tickers, recent 10-K/10-Q/8-K filings

get_corporate_registry

Incorporation data, officers, jurisdiction from OpenCorporates (140+ countries)

get_company_news

Recent news articles about any company (requires optional NewsAPI key)

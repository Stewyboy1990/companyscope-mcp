The Problem: Company Research Takes Hours

Researching a company typically means visiting 5-10 different websites: SEC EDGAR for financials, LinkedIn for key people, Crunchbase for funding, BuiltWith for tech stack, Google Patents for IP. Each has its own interface, format, and limitations.

CompanyScope aggregates 12 free public data sources into a single MCP server with 11 specialized tools. Your AI assistant calls the right tools automatically and synthesizes the results.

Getting Started (3 Options)

Option A: Cloud Hosted on Apify (Recommended)

No installation needed. Connect directly via MCP endpoint:

https://constructive-wainscot--companyscope-mcp.apify.actor/mcp

Run locally with zero configuration:

Option C: Claude Desktop

Add to your Claude Desktop config (claude_desktop_config.json):

      "command": "npx",

    }
  }
}

What You Can Research

CompanyScope provides 11 specialized tools, each pulling from different public data sources:

lookup_company Full company profile from Wikipedia, web, and registry data
get_financials SEC EDGAR filings: 10-K, 10-Q, revenue, profit margins
get_tech_stack Technologies detected via DNS, headers, and web analysis
get_key_people Executives and leadership from public sources
get_competitors Competitive landscape analysis from search data
get_patents USPTO patent filings and intellectual property
get_company_news Recent news articles and press coverage
get_corporate_registry OpenCorporates registration records
get_domain_intel WHOIS, DNS, SSL certificate analysis
get_job_postings Active job listings from career pages
get_social_presence Social media profiles and activity

Privacy Policy

CompanyScope MCP Server
Last updated: April 10, 2026

What CompanyScope Does

CompanyScope is an MCP (Model Context Protocol) server that aggregates publicly available company information from free public data sources. It provides company research tools to AI assistants like ChatGPT, Claude, and Cursor.

Data We Collect

We do not collect personal data. CompanyScope processes company research queries (company names and domains) and returns publicly available business information. We do not:

  • Collect or store user personal information
  • Require user accounts or registration
  • Use cookies or tracking pixels
  • Share data with third parties
  • Store query history beyond ephemeral request caching (max 1 hour, for performance only)

Data Sources

All data returned by CompanyScope comes from publicly available sources: Wikipedia/Wikidata, GitHub API, SEC EDGAR, OpenCorporates, DNS/RDAP records, Brave Search, Google Patents, and public company websites. No private or proprietary databases are used.

Third-Party Services

CompanyScope is hosted on Cloudflare Workers. Cloudflare may process request metadata (IP addresses, headers) per their privacy policy. We do not control or access this data.

Usage Analytics

We track aggregate usage counts (total API calls, unique users per day, per-tool usage) via Cloudflare KV. This data is anonymous — no IP addresses, user agents, or personally identifiable information is stored.
